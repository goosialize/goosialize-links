# Project Scope

## Product

Goosialize Links FREE is a self-hosted Link in Bio plugin installed on one
Grav CMS website.

It creates one responsive public page within the site's own domain, such as:

- `/bio`
- `/links`
- `/connect`

## FREE v1 Goals

The first public version must provide:

- one public link page;
- profile image or logo;
- name or brand name;
- title and short description;
- up to eight active links;
- social and contact actions;
- basic design customization;
- three basic themes;
- one downloadable QR code;
- simple first-party analytics;
- optional basic contact form;
- optional Goosialize Leads integration;
- native Grav Admin2 administration.

## Basic Analytics

The FREE dashboard contains only:

- total page views;
- total link and action clicks;
- clicks per durable link or action ID;
- QR visits.

The only approved analytics event types are:

- `page_view`
- `link_click`
- `action_click`
- `qr_visit`

The FREE edition does not record or report visitor profiles, device
information, geographic information, referrers, UTM reports, funnels, or
unique-user analytics.

## Optional Lead Capture

The link page must remain fully functional when Goosialize Leads is not
installed.

When Goosialize Leads is installed and compatible, one basic contact form may
submit a normalized lead through the public integration contract.

## Deferred to Paid Edition

The following are deferred:

- multiple link pages;
- unlimited links;
- removal of branding;
- custom CSS;
- custom fonts;
- advanced themes;
- scheduled links;
- expiring links;
- multiple QR campaigns;
- multiple forms;
- custom form fields;
- advanced analytics;
- exports;
- UTM reporting;
- referral and device reporting;
- conversion funnels;
- advanced content blocks.

## Non-Goals

The FREE v1 is not:

- a SaaS product;
- a multi-user hosted platform;
- a multi-tenant profile system;
- a frontend account dashboard;
- a payment or subscription system;
- an e-commerce builder;
- a replacement for Goosialize Leads;
- a public release of GoosBoard.

# Goosialize Links 1.0.0

Goosialize Links FREE 1.0.0 is the first stable release of the self-hosted
Link-in-Bio plugin for Grav CMS.

## Requirements

- Grav 2.0.12 or newer within the supported 2.0 line
- PHP 8.3 or newer
- Admin2 2.0.15 or newer
- Grav API plugin 1.0.12 or newer

## Highlights

- One mobile-first branded profile with up to eight Links
- Social and direct-contact Actions with stable tracking identities
- Aggregate page views, Link/Action clicks, per-item counts, and QR visits
- One tracked `qr_primary` code with PNG and SVG downloads
- Native Grav physical Page ownership and EN/EL translation workflow
- Non-destructive, idempotent Page provisioning with legacy compatibility
- Authenticated realtime preview for supported unsaved shared settings
- Shared profile image with safe saved-image and missing-image fallbacks
- Explicit permissions, privacy-preserving storage, and FREE/PAID boundaries
- Deterministic package containing locked production QR dependencies

Existing RC installations provision or preserve the native Links Page without
silently overwriting existing translated Page content. Back up the site before
upgrading and review the README for storage and retention behavior.
